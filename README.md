# Vine Theme Pack

I have tried multiple themes, and eventually end up finding little things about them I don't like and want to change, such as

- The source control colors being adapted to the theme instead of sticking to the yellow for changed files, green for new files, and red for deleted.
- I really like the unbordered look of themes, so I added an unbordered version to every theme here
- Sometimes a themes colors are really nice, but the contrast is a little off and after a while it tires out my eyes
- I like the terminal and the code editor being the same color which is sometimes different in certain themes.
- Sometimes the cursor color in themes blends in too well for me to see it.
- Some adaptations of themes from other code editors/products end up having quirks about them I don't like or don't feel quite as accurate to the original color I'd like them to be.

So yea I basically wanted to create themes that all followed a similar design pattern and are easy to spot things like git changes, errors, and just keep the themes consistent. Some theme authors will do certain things like add a different color to certain borders and what not in the editor and it just throws me off.

Feel free to improve these and open issues if something is off.

## Themes

Version 4.5.0 includes eleven palettes, each with bordered and unbordered variants, for 22 themes total.

Search matches use the same palette-matched background tones as cursor-based word highlights throughout the pack, with a stronger fill for the current match and no outlines. Both Sublime Text 4 variants refine TypeScript and TSX syntax colors to more closely match Mariana, including blue type references and teal constructors. Both Dark Modern 2026 variants pair neutral gray comments with coordinated deep charcoal surfaces and sleek bordered and unbordered styles.
